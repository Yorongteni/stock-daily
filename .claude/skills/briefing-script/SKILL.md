# 경제 앵커 대본 규칙 (SunHi TTS)

영상은 **경제를 잘 모르는 시청자를 위한 약 10분 핵심판**입니다. 리포트 섹션 화면을 순서대로 보여 주며 `script` 의 각 필드를 읽습니다.
(쉬운 요약 `easy.summary`, 용어 `glossary`, 연결고리 `chains` 장면은 프로그램이 해당 필드로 대본을 만듭니다.)
분량을 넘기면 문장 단위로 잘리므로, **가장 중요한 말을 앞에** 둡니다.

| 필드 | 화면 | 분량 (최대) |
|---|---|---|
| intro | 오프닝 (제목) | 120~200자 |
| history | ① 과거 대비 | 400~540자 |
| macro | ② 매크로·환율·금리 | 400~540자 |
| social_forecast | ③ 당일 예측 (사회 흐름 + 예상 범위·시나리오) | 500~680자 |
| sectors | ④ 13개 분야 한눈에 (강한 분야·약한 분야와 이유) | 500~680자 |
| opps_risks | ⑤ 기회 & 리스크 (각 2개) | 380~500자 |
| conclusion | ⑥ 종합 총론 (비중과 오늘의 행동 2~3개) | 450~600자 |

## 초보 시청자 원칙 (가장 중요)

- 전문 용어는 처음 말할 때 **바로 뒤에 쉬운 뜻**을 붙입니다. 예: "미국 10년 국채 금리, 쉽게 말해 전 세계 돈의 기준 이자율이".
- 숫자를 말하면 **그게 많은지 적은지**를 함께 말합니다. 예: "5년 중 가장 높은 수준입니다".
- "왜"를 **원인 → 결과**로 이어 말합니다. "~해서, ~하고, 그래서 ~입니다."
- 비유를 하나씩 써도 좋습니다. 단, 틀린 비유는 쓰지 않습니다.

## 말투

- 아침: "안녕하십니까, ○월 ○일 모닝 브리핑입니다." / 밤: "○월 ○일 나이트 브리핑입니다. 오늘 국내 증시 마감부터 보겠습니다."
- 존댓말 "~습니다/~입니다". 한 문장 60자 안팎, 길면 나눕니다.
- 각 필드의 **첫 문장은 결론**("오늘 코스피는 보합권 출발이 예상됩니다.")으로 시작하고, 그 뒤에 근거를 붙입니다.
- 화면 전환을 의식한 연결어: "이어서", "다음은", "정리하면".
- 단정은 피하지 않되 근거를 붙입니다: "~로 봅니다. 근거는 ~입니다."

## 자연스러운 연결 (TTS 어색함 방지)

- **같은 연결어를 한 문장에 반복하지 않습니다.** "~로 이어지고 ~로 이어지고 결국 ~로 이어집니다"는 금지입니다.
  `~하면`, `~해져`, `~하며`, `이는 결국 ~로 이어집니다`처럼 어미를 바꿔 씁니다.
  예: "달러 강세가 나타나면 신흥국 자산 매력이 줄어 외국인이 한국 주식을 팔고 달러로 이동하며, 이는 원화 약세와 코스피 하락 압력으로 이어집니다."
- **기간별 결과는 한 문장으로 한 번만** 말합니다. 같은 수치를 두 번 말하지 않고, 서술어를 겹치지 않습니다("상승으로 올랐습니다" 금지).
  예: "그 뒤 코스피는 1개월 뒤 10.5%, 3개월 뒤 8.2%, 6개월 뒤에는 15.0% 상승했습니다."
  `history_context.analogs[].lesson` 에는 1·3·6개월 수치를 다시 쓰지 않습니다(영상이 데이터로 읽습니다). 시사점만 씁니다.
- **기간 + 등락률은 '동안'을 넣습니다.** "60일 -28.7%" 대신 "60일 동안 28.7% 하락" ("육십일"이 "61"처럼 들리지 않게).
- 회사 이름은 한글 표기 그대로: "앤트로픽", "엔비디아". 영어로 쓰지 않습니다.

## 숫자 읽기

- 지수·환율은 반올림해 자연스럽게: "5,251포인트", "1,334원".
- 비율: "0.8%", 변화폭: "25bp", 퍼센트포인트: "3%p" — 기호는 프로그램이 읽는 말로 바꿉니다.
- 소수점은 한 자리까지. 큰 숫자 나열은 3개 이하로.
- 영어 약어는 처음에 풀어 말합니다: "공포지수 빅스(VIX)" 보다는 "공포지수 VIX" 정도로 짧게.

## 금지

- 목록 기호, 괄호 속 긴 설명, 이모지, 마크다운.
- "투자 권유가 아닙니다" 같은 면책 문구 (마무리 장면에서 자동으로 읽습니다).
- 리포트에 없는 수치를 지어내는 것.
