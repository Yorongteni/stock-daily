롱 / 숏롱은 오르면 수익, 숏은 내리면 수익. 선물은 하락장에서도 숏으로 수익을 낼 수 있어요.
펀딩비무기한 선물 가격을 현물에 맞추려고 8시간마다 롱·숏이 주고받는 이자. 크게 플러스면 롱이 과열된 상태예요.
미결제약정 (OI)아직 정리되지 않은 선물 계약 총액. 가격과 함께 늘면 새 돈이 그 방향으로 들어온다는 뜻이에요.

실제로 다르게 샀거나 팔았다면 (스마트폰)

  • GitHub 앱 → stock-daily → Actions → 보유 포지션 수동 입력 → Run workflow
  • market(US_STOCK / BINANCE), action(BUY 신규·단가수정 / CLOSE 매도·청산 / CANCEL 미체결 취소), ticker(NVDA · SOLUSDT), direction(LONG/SHORT), price, qty 입력
  • 코인 qty: 숫자만 넣으면 투입 증거금 USDT(예: 360), 코인 수량이면 '개'를 붙여요(예: 7.6개). 비우면 360 USDT
